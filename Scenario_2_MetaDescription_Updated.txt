Тестируется формирование первичных и вторичных условных рефлексов, сенсорная прекондиция (перенос реакции через склейку стимулов разных модальностей), суммация крепости и конкурентное подавление при компаундной стимуляции на 1 стадии развития агента.

Образ восприятия агента включает вербальные (фразы с пульта), тактильные (воздействия с пульта) и зрительные (цвет фона сцены) компоненты; составной (компаундный) стимул может объединять любые из этих модальностей.

ВАЖНО: для механизмов суммации (IV), смешанного ответа (V) и конкурентного подавления (VI) стимулы компаунда должны принадлежать РАЗНЫМ модальностям (вербальный + зрительный). Два стимула одной модальности (например две фразы) не распознаются системой как компаунд, потому что CompoundModalityCount считает число задействованных каналов (фразы, воздействия, цвет), а не число стимулов.

═══════════════════════════════════════════════════════════════
I. Формирование первичного условного рефлекса
═══════════════════════════════════════════════════════════════

Механизм:
Первичный условный рефлекс (CR1) образуется путём многократного сочетания нейтрального стимула (CS) с безусловным стимулом (US), вызывающим безусловный ответ (UR). После достаточного числа повторений CS начинает самостоятельно вызывать условный ответ (CR), функционально эквивалентный UR. Нейтральный стимул может быть вербальным (фраза), зрительным (цвет фона) или составным (сочетание нескольких модальностей).

Математическая модель:
Крепость ассоциативной связи C ∈ [0, 1] при повторных подкреплениях нарастает по модели Рескорла–Вагнера:

  C(k) = C(k−1) + α · (β − C(k−1))
 
где α ∈ (0, 1) — коэффициент обучения, β = 1.0 — асимптотический максимум. Периодически применяется адаптивное затухание: чем выше достигнутая крепость, тем медленнее ослабляется связь. Условный рефлекс активируется при C ≥ γ (порог активации, по умолчанию 0.6). При падении C ниже минимального порога C_min связь разрывается и рефлекс удаляется.

Протокол формирования:

Шаг 1. Предъявление CS: оператор посылает вербальный стимул с пульта (например, фраза «Эх»).
Шаг 2. Предъявление US: оператор посылает гомеостатическое воздействие (например, [Огорчить]) в пределах временного окна τ. Агент отвечает безусловной реакцией [Грустит]. Побочный эффект US — временное изменение состояния гомеостаза (Плохо) и стилей реагирования.
Шаг 3. Пауза: ожидание возврата гомеостаза в исходное состояние (Норма). Длительность определяется настройками удержания временного состояния.
Шаг 4. Повторение пары CS → US (шаги 1–3) многократно. При каждом повторе крепость C нарастает по формуле Рескорла–Вагнера.
Шаг 5. Тестовое предъявление CS без US. При C ≥ γ агент отвечает условной реакцией [Грустит] — первичный условный рефлекс сформирован.

Критерий успеха: нейтральный стимул (CS) без подкрепления вызывает реакцию безусловного рефлекса.

═══════════════════════════════════════════════════════════════
II. Формирование вторичного условного рефлекса
═══════════════════════════════════════════════════════════════

Механизм:
Вторичный условный рефлекс (CR2) образуется на базе уже сформированного первичного. В роли безусловного стимула выступает условный стимул первичного рефлекса (CS1), а в роли нового условного — новый нейтральный стимул (CS2).

Особенности высших порядков:
- Коэффициент понижения K ∈ [1.2, 3.0] (задаётся в настройках) замедляет обучение и ускоряет затухание: α' = α/K, η' = η^K.
- Третичный рефлекс (от вторичного) использует удвоенный коэффициент: α' = α/(K·2), η' = η^(K·2) — такие рефлексы
  формируются существенно медленнее и распадаются быстрее.
- При усилении родительского рефлекса каскадно усиливаются дочерние.

Протокол формирования:

Шаг 1. Убедиться, что первичный CR1 сформирован и стабильно активируется на CS1.
Шаг 2. Предъявление CS2: оператор посылает новый вербальный стимул (например, «Ох»).
Шаг 3. Предъявление CS1: оператор посылает вербальный стимул первичного рефлекса («Эх»), который вызывает условную реакцию CR1.
Шаг 4. Повторение пары CS2 → CS1 многократно. Крепость вторичного рефлекса нарастает с понижающим коэффициентом.
Шаг 5. Тестовое предъявление CS2 без CS1. При достаточной крепости агент отвечает реакцией, унаследованной от первичного рефлекса, — вторичный условный рефлекс сформирован.

Критерий успеха: CS2 без подкрепления вызывает реакцию, опосредованную через первичный условный рефлекс.

═══════════════════════════════════════════════════════════════
III. Сенсорная прекондиция (перенос через склейку)
═══════════════════════════════════════════════════════════════

Механизм:
Реакция, закреплённая за составным стимулом, автоматически переносится на его отдельный компонент, если этот компонент ранее входил в состав того же образа восприятия (был «склеен» с другим стимулом при формировании рефлекса). Перенос осуществляется по иерархии «часть — целое»: при предъявлении одиночного компонента он распознаётся как часть ранее сформированного составного образа.

Формула:

  CS₁ + CS₂ (одновременно) + US → CR на составной образ I₁₂

  CS₂ (одиночно) → R (автоматический перенос)

где CS₁ — стимул одной модальности (например, вербальный),
    CS₂ — стимул другой модальности (например, зрительный),
    I₁₂ — составной образ восприятия, содержащий оба компонента.

Совместимость одиночного стимула с составным образом устанавливается при выполнении условия подмножества:
  все модальности предъявленного стимула содержатся в пусковом образе рефлекса. Белый цвет (White = 0) интерпретируется как «отсутствие зрительного сигнала» и не конфликтует ни с каким цветом в образе рефлекса. Два различных ненулевых цвета (например, Красный и Зелёный) конфликтуют.

Экспериментальная база:
— Brogden W.J. (1939). Sensory pre-conditioning — звонок+свет, затем звонок+ток → свет даёт реакцию на ток.
— Rizley R.C., Rescorla R.A. (1972). Associations in second-order conditioning and sensory preconditioning. JCPP, 81(1), 1–11.

Протокол тестирования:

Шаг 1. Склейка и обучение: оператор устанавливает цвет фона сцены (например, Красный) и посылает фразу «Ах» с пульта. Затем в пределах временного окна τ посылает US [Огорчить]. Агент отвечает безусловной реакцией [Грустит]. Условный рефлекс формируется на составной образ восприятияь{фраза «Ах» + Красный фон}.
Шаг 2. Повторение (шаг 1) 3–4 раза. Крепость нарастает по модели Рескорла–Вагнера до C ≥ γ.
Шаг 3. Тест прямого совпадения: предъявить «Ах» + Красный фон (без US). Ожидается реакция [Грустит] — полное совпадение с образом рефлекса.
Шаг 4. Тест переноса (зрительный компонент): оператор устанавливает Красный фон, НЕ посылает фразу. Предъявлен только зрительный компонент. Ожидается реакция [Грустит] — зрительный стимул распознаётся как часть составного образа {«Ах» + Красный}: пустой вербальный компонент является подмножеством любого вербального списка при совпадении цвета.
Шаг 5. Тест переноса (вербальный компонент): оператор устанавливает цвет Белый (сброс), посылает фразу «Ах» без цвета. Ожидается реакция [Грустит] — вербальный стимул распознаётся как часть составного образа: фраза «Ах» содержится в пусковом образе, а белый цвет (отсутствие сигнала) не конфликтует с Красным.
Шаг 6. Контрольный тест (зрительный): оператор устанавливает другой цвет (например, Зелёный), НЕ посылает фразу. Два различных ненулевых цвета конфликтуют.
Шаг 7. Контрольный тест (вербальный): оператор устанавливает цвет Белый, посылает фразу «Бу» (не входящую в образ). Ожидается отсутствие реакции — фраза «Бу» не является подмножеством [«Ах»].

Критерий успеха шага 4: зрительный стимул без вербального вызывает реакцию (перенос через склейку).
Критерий успеха шага 5: вербальный стимул без зрительного вызывает реакцию (перенос через склейку).
Критерий успеха шагов 6–7: нерелевантные стимулы не вызывают реакции (специфичность переноса).

═══════════════════════════════════════════════════════════════
IV. Суммация крепости при компаундном стимуле
═══════════════════════════════════════════════════════════════

ВАЖНО: компаундный стимул должен задействовать МИНИМУМ ДВЕ МОДАЛЬНОСТИ (вербальную + зрительную). Два стимула одной модальности (две фразы) не распознаются как компаунд: CompoundModalityCount считает число задействованных каналов, а не стимулов.

Механизм:
При совместном предъявлении двух стимулов разных модальностей (S₁ + S₂), каждый из которых имеет условный рефлекс к одному и тому же безусловному ответу, их крепости суммируются:

  C_combined = min(1.0, C₁ + C₂)

Активация происходит при C_combined ≥ γ, даже когда каждый C_i < γ по отдельности. Система декомпозирует составной образ восприятия на компоненты по модальностям и сопоставляет каждый компонент с пусковыми стимулами существующих условных рефлексов.

Экспериментальная база:
— Rescorla R.A. (1997). Summation and overexpectation with qualitatively different outcomes. ALB, 25(1), 50–62.
— Weiss S.J. (1972). Stimulus compounding in free-operant and classical conditioning. PB, 78(3), 189–208.

Протокол тестирования:

Шаг 1. Сформировать CR1: пара «фраза А1» (вербальный канал) + воздействие [В] (повтор 2–3 раза). Довести крепость CR1 до ~0.3–0.4 (ниже порога γ = 0.6). Цвет фона при обучении — Белый (по умолчанию).
Шаг 2. Сформировать CR2: «цвет Красный» (зрительный канал, без фразы) + то же воздействие [В] (повтор 2–3 раза). Довести крепость CR2 до ~0.3–0.4.
Шаг 3. Предъявить «А1» одиночно (Белый фон) — реакции нет (C₁ < γ).
Шаг 4. Предъявить Красный фон одиночно (без фразы) — реакции нет (C₂ < γ).
Шаг 5. Предъявить «А1» + Красный фон одновременно (вербальный + зрительный каналы в одном пульсе) — ожидается реакция безусловного рефлекса [В]: C₁ + C₂ ≈ 0.3 + 0.3 = 0.6 ≥ γ.

Критерий успеха: компаундный стимул из двух модальностей вызывает реакцию, недостижимую для каждого компонента по отдельности.

═══════════════════════════════════════════════════════════════
V. Суммация (оба рефлекса при близкой силе)
═══════════════════════════════════════════════════════════════

ВАЖНО: как и в разделе IV, стимулы должны принадлежать РАЗНЫМ модальностям (вербальный + зрительный).

Механизм:
Если два стимула разных модальностей предъявлены вместе, и каждый имеет условный рефлекс к разным безусловным ответам с близкой крепостью, активируются оба ответа одновременно (смешанный ответ).

Формула:

  S₁ + S₂ → R₁ и R₂ (оба ответа активируются)

  θ = min(C₁, C₂) / max(C₁, C₂)

Оба ответа активируются при θ ≥ θ_comp (по умолчанию 0.7), то есть когда крепости обоих рефлексов достаточно близки. Каждый рефлекс при этом должен превышать порог активации: C_i ≥ γ.

Экспериментальная база:
— Weiss S.J. (1972). Stimulus compounding in free-operant and classical conditioning — компаунд вызывает смешанные или суммарные реакции. PB, 78(3), 189–208.
— Rescorla R.A. (1997). Summation and overexpectation with qualitatively different outcomes. ALB, 25(1), 50–62.

Протокол тестирования:

Шаг 1. Сформировать CR1: «фраза Б1» (вербальный канал) → безусловный [В1] (например, [Огорчить]). Повторить 4–5 раз. Довести крепость до C₁ ≈ 0.8. Цвет фона при обучении — Белый.
Шаг 2. Сформировать CR2: «цвет Красный» (зрительный канал, без фразы) → безусловный [В2] (например, [Порадовать]). Повторить 4–5 раз. Довести крепость до C₂ ≈ 0.8.
Шаг 3. Предъявить «Б1» + Красный фон одновременно (вербальный + зрительный каналы). Отношение крепостей: θ = 0.8/0.8 = 1.0 ≥ θ_comp = 0.7. Ожидается смешанный ответ: обе реакции ([Грустит] и [Радуется]).

Критерий успеха: оба безусловных ответа активируются одновременно при близких крепостях условных рефлексов (θ ≥ θ_comp).

═══════════════════════════════════════════════════════════════
VI. Конкурентное подавление (выбор по силе)
═══════════════════════════════════════════════════════════════

ВАЖНО: как и в разделах IV–V, стимулы компаунда — разных модальностей (вербальный + зрительный).

Механизм:
При предъявлении компаунда стимулов разных модальностей с условными рефлексами к разным безусловным ответам и существенно различающейся крепостью более сильный рефлекс подавляет более слабый. Активируется только доминирующий ответ.

Формула:

  S₁ + S₂ → R₁ или R₂ (только более сильный рефлекс)

  θ = min(C₁, C₂) / max(C₁, C₂)

При θ < θ_comp (по умолчанию 0.7) активируется только рефлекс с большей крепостью (при условии C_max ≥ γ). Рефлекс с меньшей крепостью полностью подавляется.

Экспериментальная база:
— Kamin L.J. (1969). Predictability, surprise, attention, and conditioning. In: Campbell B.A., Church R.M. (Eds.), Punishment and Aversive Behavior. Appleton-Century-Crofts.
— Bouton M.E., Nelson J.B. (1994). Context-specificity of target versus feature inhibition. JEPABP, 20(1), 51–65.
— Mackintosh N.J. (1976). Overshadowing and stimulus intensity. ALB, 4(2), 186–192.

ВАЖНО: оба рефлекса должны иметь крепость ВЫШЕ порога активации γ = 0.6, иначе слабый
рефлекс и так не активируется и тест теряет смысл. Разница в крепостях должна быть
достаточной для θ < θ_comp = 0.7, но оба C ≥ γ.

Протокол тестирования:

Шаг 1. Использовать CR1 и CR2, сформированные в разделе V (C₁ ≈ 0.8, C₂ ≈ 0.8).
Шаг 2. Прекратить подкрепление CR2 (Красный → [В2]). Дождаться затухания крепости до C₂ ≈ 0.62–0.65
       (чуть выше порога γ = 0.6, но θ = 0.62/0.8 ≈ 0.78... — это ещё ≥ 0.7, значит надо ждать дальше).
       Целевая крепость: C₂ ≈ 0.55·C₁, т.е. при C₁ = 0.9 нужно C₂ ≈ 0.61–0.62, чтобы θ ≈ 0.68 < 0.7.
       Альтернативный вариант: задать крепости вручную в авторитарном режиме, например C₁ = 0.9, C₂ = 0.62.
Шаг 3. Предъявить «Б1» + Красный фон одновременно (вербальный + зрительный каналы).
       Отношение крепостей: θ = 0.62/0.9 ≈ 0.69 < θ_comp = 0.7.
       Ожидается только реакция [В1] — ответ сильнейшего рефлекса. Реакция [В2] подавлена.
       (Примечание: C₂ = 0.62 ≥ γ = 0.6, т.е. по отдельности CR2 активировался бы, но в компаунде подавлен.)

Критерий успеха: при θ < θ_comp активируется только ответ сильнейшего рефлекса, слабый подавляется,
несмотря на то что его крепость превышает порог активации γ.

═══════════════════════════════════════════════════════════════
Параметры модели
═══════════════════════════════════════════════════════════════

  α       = 0.2   — коэффициент обучения
  β       = 1.0   — асимптотический максимум крепости
  η       = 0.98  — коэффициент затухания
  γ       = 0.6   — порог активации
  τ       = 5     — временное окно корреляции (в пульсах)
  C_min   = 0.1   — минимальная крепость связи
  K       = 1.5   — коэффициент понижения для вторичных рефлексов
  θ_comp  = 0.7   — порог отношения крепостей для суммации / конкурентного подавления
