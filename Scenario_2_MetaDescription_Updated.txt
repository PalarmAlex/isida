Заголовок (первая часть SCENARIO_META):
Стадия 1. Формирование первичных и вторичных условных рефлексов

Краткое описание (вторая часть SCENARIO_META — одна строка с \n для переносов при вставке в .dat):

Стадия 1. Формирование первичных и вторичных условных рефлексов. Суммация и конкурентное подавление. Зрительский канал и компаунд по модальностям.

Тестируется формирование первичных и вторичных условных рефлексов, эффекты суммации крепости и конкурентного подавления при компаундной стимуляции на 1-й стадии развития агента.

Дополнения к модели восприятия:
— Пусковой образа восприятия (PerceptionImage) включает вербальный компонент (идентификатор фразы) и зрительский: идентификатор цвета фона (0 — белый, 1–7 — оттенки, 8 — чёрный). По умолчанию на пульте — белый (0); ненулевой цвет участвует в активации так же, как отдичие фразы от «пустой».
— В данных PerceptionImages.dat четвёртый столбец после разделителя | задаёт visualColorId; для старых строк без столбца при загрузке подставляется 0.

Иерархия модальностей при конкуренции условных рефлексов к разным UR:
— Сначала рассматриваются рефлексы с наибольшим числом различных модальностей в пусковом стимуле (compound modality count): уровень 3 выше 2, 2 выше 1.
— Внутри одного уровня при нескольких кандидатах на один и тот же UR крепости эффективно суммируются по группе (суммация для компаунда к одному ответу).
— Между разными UR на том же уровне иерархии действует порог отношения крепостей (CompetitionStrengthRatioThreshold): при высокой близости крепостей возможен смешанный ответ, иначе побеждает более сильный рефлекс.
— При полном равенстве крепости победителя выбирает настройка ничьей по идентификатору рефлекса (по умолчанию — меньший id).

Временное окно компаунда:
— Несколько пусковых стимулов (в том числе две фразы в одном пульсе и/или сочетание фразы с ненулевым цветом) учитываются в пределах окна по числу пульсов (TimeWindowPulses), задаваемого в настройках обусловливания.

III. Суммация крепости при компаундном стимуле (вербал + зрение)
═══════════════════════════════════════════════════════════════

Механизм:
При совместном предъявлении двух пусковых компонентов (например, две разные фразы в одном пульсе, либо одна фраза и ненулевой цвет фона), каждый из которых связан с тем же UR, эффективные крепости участвующих рефлексов суммируются (с ограничением сверху), и активация возможна при суммарной крепости ≥ γ, даже если отдельно каждая ниже порога.

Протокол тестирования (аналогично исходному разделу III, с уточнением):

Шаг 1–2. Сформировать два рефлекса к одному US с крепостью каждого ниже γ.
Шаг 3–4. Одиночные предъявления — без ответа.
Шаг 5. Компаунд: оба стимула в одном пульсе (две фразы и/или фраза + выбранный на пульте цвет ≠ белый) — ожидается ответ по суммарной крепости.

Критерий успеха: компаундный стимул вызывает реакцию, недостижимую для каждого компонента по отдельности.
