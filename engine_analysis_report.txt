1. CORE ENGINE STRUCTURE
================================================================================

1.1 Main Entry Point
--------------------
- The isida project is a class library (OutputType=Library); it has no static
  void Main. The engine is created by the host application.
- Engine creation entry: IsidaEngine.Create(IsidaConfig config)
  File: Common\IsidaEngine.cs
  Class: IsidaEngine (static)
  Method: Create(IsidaConfig config) → IsidaContext
- Alternative: IsidaEngine.CreateWithDefaults(string baseDirectory = null) builds
  IsidaConfig with WithDefaultFolders() and calls Create(config).
- Host responsibility: The host (e.g. AIStudio MainViewModel) builds IsidaConfig,
  calls IsidaEngine.Create(config), and holds IsidaContext. The host also calls
  GlobalTimer.Start() to begin the main loop (after engine is created and
  EvolutionStage >= 1).

1.2 Configuration
-----------------
- Primary config: IsidaConfig (Common\IsidaEngine.cs). In-memory only; no config
  file or env vars are read inside the engine. The host constructs and passes it.
- IsidaConfig.Validate() enforces: GomeostasFolder, ActionsFolder, SensorsFolder,
  ReflexesFolder, PsychicDataFolder, LogsFolder, BootDataFolder non-empty.
- Key parameters:
  - Paths: BaseDirectory, GomeostasFolder, ActionsFolder, SensorsFolder,
    ReflexesFolder, PsychicDataFolder, LogsFolder, BootDataFolder
  - Logging: LogFormat, LogEnabled, ClearLogsOnStart, MemoryLogWriter
  - Behavior: DefaultStileId, CompareLevel, DifSensorPar, DynamicTime,
    ReflexActionDisplayDuration, DefaultAdaptiveActionId, RecognitionThreshold,
    WaitingPeriodForActionsVal
- WithDefaultFolders(): sets all folder paths relative to BaseDirectory
  (e.g. DataGomeostas, DataActions, Sensors, Reflexes, Data\Psychic, Logs, BootData).
- File-based config (subsystem): ConditionedReflexesSystem loads
  ConditionedReflexSettings from ConditionedReflexSettings.dat (key=value lines)
  via LoadConditionedReflexSettings(); path from GetConditionedReflexSettingsFilePath().
- Validation: SettingsValidator (Common\SettingsValidator.cs) validates numeric
  settings (RecognitionThreshold, CompareLevel, DifSensorPar, DynamicTime,
  LearningRate, DecayRate, etc.) used by Gomeostas and ConditionedReflexes.

1.3 Main Execution Loop Architecture
------------------------------------
- Mechanism: Timer-based pulse loop (no while-loop or external scheduler).
- File: Common\GlobalTimer.cs (static class GlobalTimer).
- Loop driver: System.Threading.Timer with callback TimerCallback. Single-shot
  scheduling: timer fires once per cycle, then is rescheduled with
  _timer?.Change(GrayDurationMs, Timeout.Infinite).
- Pulse cycle (one “tick” ≈ 1 s):
  - GreenDurationMs = 200 ms: pulse on, brightness 1.0
  - FadeDurationMs = 300 ms: stepwise fade (10 steps)
  - Then ProcessAgentPulse() runs (core logic)
  - GrayDurationMs = 500 ms: pause; then timer rescheduled
- There is no separate event bus; the loop is strictly sequential. External
  “events” are InfluenceActionSystem (TriggerStimulusActivated, PhraseStimulusActivated)
  which ReflexesActivator subscribes to; they are invoked from outside the timer
  when the host feeds stimuli.
- Start/Stop: GlobalTimer.Start() requires InitializeSystems() to have been
  called and AppGlobalState.EvolutionStage >= 1; Start() sets _isRunning = true,
  creates the pulse timer and a 1 s interval autosave timer. GlobalTimer.Stop()
  clears _isRunning and disposes both timers.

2. STAGES OF OPERATION
================================================================================

2.1 Stage: Initialization
-------------------------
- Stage Name: Init
- Trigger: Host calls IsidaEngine.Create(config). No timer running yet.
- Active Modules/Classes: IsidaEngine, IsidaContext; all subsystems via
  InitializeEngine(context, config) in 34 steps (see list below).
- Key Methods: IsidaEngine.Create(config), IsidaEngine.InitializeEngine(context, config).
- Data Flow:
  - Input: IsidaConfig (paths, flags, thresholds).
  - Transform: 34-step init: (1) logs/dirs, (2–3) InformationEnvironmentSystem,
    GomeostasSystem, (4–5) AdaptiveActionsSystem, InfluenceActionSystem,
    (6) InfluenceActionsImagesSystem, (7) SensorySystem, (8–10) GeneticReflexesSystem,
    ReflexChainsSystem, GeneticReflexFileLoader, (11) PerceptionImagesSystem + wiring,
    (12–16) ConditionedReflexesSystem, ReflexTreeSystem, ReflexExecutionService,
    ConditionedReflexFormationService, ReflexesActivator, (17) ResearchLogger +
    GlobalTimer.SetResearchLogger, (18–21) ActionsImagesSystem, AutomatizmTreeSystem,
    ProblemTreeSystem, AutomatizmSystem, (22–26) EmotionsImageSystem,
    VerbalBrocaImagesSystem, AutomatismResultTracker, EpisodicMemorySystem,
    PsychicSystem, (27–34) PurposeGeneticImageSystem, AutomatizmFileLoader,
    AutomatismExecutionService, OrientationReflexSystem, AutomatizmChainsSystem,
    AutomatismExecutionService.InitializeWithDependencies, ConditionedReflexToAutomatizmConverter,
    EvolutionStageService, GlobalTimer.InitializeSystems, SetConditionedReflexesSystem,
    SetReflexFormationService.
  - Output: Fully populated IsidaContext; GlobalTimer holds references to
    Gomeostas, AdaptiveActionsSystem, ReflexesActivator, PsychicSystem.
- State Changes: All subsystem singletons/instances set; AppGlobalState.WaitingPeriodForActionsVal
  set from config; EvolutionStage remains at host-set value (typically 0 until host
  advances it).
- Exit Condition: InitializeEngine returns (or throws IsidaInitializationException).
  Host then may set EvolutionStage and call GlobalTimer.Start().

2.2 Stage: Idle (Pulse Stopped)
-------------------------------
- Stage Name: Idle
- Trigger: GlobalTimer.Stop() has been called, or Start() never called.
- Active Modules/Classes: None in the loop; host holds IsidaContext.
- Key Methods: (none in engine loop).
- Data Flow: N/A.
- State Changes: _isRunning = false; IsPulsationRunning = false; timers disposed;
  OnPulsationStopped() runs: AppGlobalState.ForceStopWaitingForOperatorEvaluation(),
  _actionsSystem.ClearAllActiveState(), AppGlobalState.ClearPulseIndicators(),
  _gomeostas.ClearPulseRuntimeIndicators().
- Exit Condition: Host calls GlobalTimer.Start() (and EvolutionStage >= 1).

2.3 Stage: Pulse (Running) — Per-Tick Phases
--------------------------------------------
- Stage Name: Processing (single pulse)
- Trigger: TimerCallback fires every ~1 s (after green + fade). Internal condition:
  _isRunning true and _timer non-null.
- Active Modules/Classes: GlobalTimer, GomeostasSystem, PsychicSystem,
  ConditionedReflexesSystem, ReflexesActivator, AdaptiveActionsSystem,
  ResearchLogger, AppGlobalState.
- Key Methods (in order within one pulse):
  1. OnPulseStateChanged(true), OnPulseBrightnessChanged(1.0); Thread.Sleep(200).
  2. Fade loop: OnPulseBrightnessChanged(i*0.1); Thread.Sleep(30) x10.
  3. GlobalPulsCount++; _gomeostas.PulseCount = GlobalPulsCount; ProcessAgentPulse().
  4. _timer.Change(GrayDurationMs, Timeout.Infinite); Monitor.Pulse(_timerLock).

ProcessAgentPulse() (GlobalTimer.cs) order:
  1. _gomeostas.UpdateStateOnly()
  2. If AppGlobalState.IsDead → SafeStopWithAgentDeath(); return.
  3. Else: activetStyleIds = AppGlobalState.ActiveStyles IDs; sleepingType = 0;
     _psychicSystem.ProcessPsychicPulse(activetStyleIds, GlobalPulsCount, sleepingType)
  4. If HasConditionedReflexesSystem: _conditionedReflexesSystem.UpdateAgentLifetime()
  5. If !AppGlobalState.IsSleeping: _reflexesActivator.ProcessReflexPulse(GlobalPulsCount, IsSleeping)
  6. If !IsDead: _actionsSystem.CleanupExpiredReflexActions()
  7. If ResearchLogger active and !IsDead: OnPulseCompleted?.Invoke(GlobalPulsCount)
  8. finally: AppGlobalState.IsNewConditions = false;
     _reflexesActivator.ResetStates(GlobalPulsCount)

- Data Flow (per pulse):
  - Input: Previous parameter state, active styles, pulse count, IsSleeping (from
    AppGlobalState; sleepingType currently always 0 — see “Sleep” stage).
  - Transform: UpdateStateOnly (params, state, styles, critical check);
    ProcessPsychicPulse (stage ≥2: automatism chains, evaluation window);
    UpdateAgentLifetime + ApplyDecay (conditioned reflexes);
    ProcessReflexPulse (chains, condition change, activation);
    CleanupExpiredReflexActions (remove old reflex actions from display).
  - Output: Updated AppGlobalState (Lifetime, CurrentOverallState, ActiveStyles,
    IsDead, etc.); AdaptiveActions active list; ResearchLogger writes; OnPulseCompleted
    event.
- State Changes: GlobalPulsCount incremented; GomeostasSystem internal state
  (parameters, overall state, active styles, HasCriticalChanges); AppGlobalState
  (Lifetime, IsDead if critical, ActiveStyles, etc.); ReflexesActivator internal
  chain/trigger state; ConditionedReflexesSystem _currentAgentLifetime and decay;
  AdaptiveActionsSystem _activeActions pruned.
- Exit Condition: End of ProcessAgentPulse; timer rescheduled for next tick.
  If IsDead, SafeStopWithAgentDeath() stops the loop (see “Death” stage).

2.4 Stage: Homeostasis Update (Substep)
---------------------------------------
- Stage Name: Homeostasis update (within Processing).
- Trigger: Every pulse; first step of ProcessAgentPulse().
- Active Modules/Classes: GomeostasSystem, GomeostasCalculator (via _calculator),
  InformationEnvironmentSystem, AppGlobalState.
- Key Methods: GomeostasSystem.UpdateStateOnly().
  Internal: SaveParametersState(); HasCriticalChanges =
  _calculator.HasCriticalParameterChanges(...); _informationEnvironmentSystem
  .SetVeryActualSituation(HasCriticalChanges); foreach param: value += Speed/100
  (or /10 if sleeping), param.UpdateState(...); CalculateAgentState(...);
  UpdateNoveltyDetector(...); UpdateActiveStyles(); CheckForCriticalState().
- Data Flow:
  - Input: _agentState.Parameters, _previousParametersState, _dynamicTime,
    _difSensorPar, _compareLevel.
  - Transform: Parameter drift; agent state (Bad/Normal/Well); active styles;
    critical check (vital param outside [CriticalMinValue, CriticalMaxValue]).
  - Output: _currentOverallState, AppGlobalState.CurrentOverallState and
    ActiveStyles; _agentState.Lifetime++, AppGlobalState.Lifetime++;
    InformationEnvironmentSystem.SetLifeTime(...). If critical:
    _agentState.IsDead = true, AppGlobalState.IsDead = true, OnAgentDeath(param).
- State Changes: Parameter values; LastWellStatePulse; _previousOverallState,
  _previousActiveStyleIds; AppGlobalState.UpdateActiveStyles(...); possibly IsDead.

2.5 Stage: Psychic Pulse (Substep)
----------------------------------
- Stage Name: Psychic processing (within Processing).
- Trigger: Every pulse after UpdateStateOnly, if !IsDead.
- Active Modules/Classes: PsychicSystem, AutomatismExecutionService,
  AutomatizmSystem, MirrorAutomatizmService (evaluation).
- Key Methods: PsychicSystem.ProcessPsychicPulse(activetStyleIds, pulseCount, sleepingType).
- Data Flow:
  - Input: activetStyleIds (from AppGlobalState.ActiveStyles), GlobalPulsCount,
    sleepingType (0 in current code).
  - Transform: If EvolutionStage < 2: return. Set PulseCount, LifeTime, IsSleeping
    from sleepingType. If !IsSleeping: (1) If stage > 3 and PulseCount > 4 and
    WakeUppingActivation: WakeUpping(activetStyleIds), AutomatizmTreeActivation(...),
    WakeUppingActivation = false; (2) If WaitingForOperatorEvaluation: evaluate
    time window, optionally EvaluatePreviousAutomatizm → mirrorAutomatizmToExecute;
    (3) _automatismExecutionService.ProcessAutomatizmChainsPulse(pulseCount). If
    IsSleeping: ProcessSleep(). If mirrorAutomatizmToExecute > 0: ExecuteAutomatizm(...).
  - Output: Possible execution of one mirror automatism; internal psychic state
    (current/previous automatism, waiting state).
- State Changes: PsychicSystem PulseCount, LifeTime, IsSleeping, IsSleepingDream;
  WakeUppingActivation; _currentAutomatizmId / _previousAutomatizmId; waiting
  state; AutomatismExecutionService chain state.
- Exit Condition: End of ProcessPsychicPulse (same pulse continues to reflexes).

2.6 Stage: Conditioned Reflex Lifetime (Substep)
-----------------------------------------------
- Stage Name: Conditioned reflex update (within Processing).
- Trigger: Every pulse if !IsDead and ConditionedReflexesSystem is set.
- Active Modules/Classes: ConditionedReflexesSystem.
- Key Methods: ConditionedReflexesSystem.UpdateAgentLifetime().
  Internal: _currentAgentLifetime = AppGlobalState.Lifetime; ApplyDecay().
- Data Flow:
  - Input: AppGlobalState.Lifetime.
  - Transform: ApplyDecay() (decay of conditioned reflex strengths per settings).
  - Output: Updated conditioned reflex internal state (strengths).
- State Changes: _currentAgentLifetime; conditioned reflex strengths.
- Exit Condition: Method return.

2.7 Stage: Reflex Pulse (Substep)
--------------------------------
- Stage Name: Reflex activation (within Processing).
- Trigger: Every pulse if !AppGlobalState.IsSleeping.
- Active Modules/Classes: ReflexesActivator, ReflexTreeSystem, ReflexChainsSystem,
  ReflexExecutionService, ConditionedReflexFormationService, PerceptionImagesSystem,
  InfluenceActionSystem, AdaptiveActionsSystem.
- Key Methods: ReflexesActivator.ProcessReflexPulse(pulseCount, isSleeping).
  Internal: DeactivateChain (if IsNewConditions or chain completed + duration);
  ProcessActiveChain; ActivatePendingChain if due; if !_isChainActive:
  ActiveFromConditionChange when appropriate; also event-driven ActiveFromAction
  / ActiveFromPhrase from InfluenceActionSystem.
- Data Flow:
  - Input: GlobalPulsCount, AppGlobalState.IsSleeping, AppGlobalState.IsNewConditions,
    chain state, pending chain, cooldown.
  - Transform: Process active reflex chain steps; optionally activate new chain
    from condition change (style/base) or from trigger/phrase events.
  - Output: Reflex actions executed via ReflexExecutionService; AppGlobalState
    GeneticReflexesActions / ConditionedReflexesActions updated; active adaptive
    actions displayed.
- State Changes: _isSleeping, _currentPulse; chain active/pending/cooldown;
  _activeCur* IDs; _geneticReflexesToRun, _conditionedReflexesToRun;
  AppGlobalState.FlgConditionReflexes; AppGlobalState.UpdateGlobalGeneticReflexesActions
  / UpdateGlobalConditionedReflexesActions.
- Exit Condition: End of ProcessReflexPulse.

2.8 Stage: Cleanup & Reset (End of Pulse)
-----------------------------------------
- Stage Name: Cleanup and state reset (within Processing).
- Trigger: After reflex pulse and action cleanup; in ProcessAgentPulse’s finally.
- Active Modules/Classes: AdaptiveActionsSystem, ReflexesActivator, AppGlobalState.
- Key Methods: AdaptiveActionsSystem.CleanupExpiredReflexActions();
  AppGlobalState.IsNewConditions = false; ReflexesActivator.ResetStates(GlobalPulsCount).
  CleanupExpiredReflexActions: remove actions where (GlobalPulsCount - ActivationPulse)
  >= ReflexActionDisplayDuration; update AppGlobalState.UpdateActiveAdaptiveActions.
  ResetStates: clear _activeCur* IDs, _activeGeneticReflexID, _activeConditionReflexID,
  _geneticReflexesToRun, _conditionedReflexesToRun; FlgConditionReflexes = false;
  repopulate *ToRun from current condition via GetActionsForConditionReflexToRun,
  GetActionsForGeneticReflexToRun.
- Data Flow:
  - Input: _activeActions, GlobalPulsCount, ReflexActionDisplayDuration; current
    condition (styles/base) for reflex lists.
  - Output: Pruned active actions; refreshed “reflexes to run” lists for next pulse.
- State Changes: _activeActions and _activeActionPhrases; AppGlobalState
  ActiveAdaptiveActions; ReflexesActivator trigger/reflex IDs and to-run lists.
- Exit Condition: End of finally block; OnPulseCompleted raised if applicable.

2.9 Stage: Autosave
-------------------
- Stage Name: Autosave
- Trigger: Time-based; separate timer (1 s interval). Every AutosaveIntervalSeconds (10)
  seconds TriggerAutosave() runs.
- Active Modules/Classes: GlobalTimer, GomeostasSystem.
- Key Methods: AutosaveCallback (increment _secondsSinceLastSave; when >= 10 call
  TriggerAutosave()); TriggerAutosave(): _gomeostas.SaveAgentProperties();
  OnAutosave?.Invoke().
- Data Flow:
  - Input: _agentState (name, description, IsSleeping, IsDead, Lifetime,
    EvolutionStage, PainValue, JoyValue, archetype, motivation, etc.).
  - Output: Agent properties file (e.g. AgentPropertiesFileName.dat) under
    GomeostasFolder.
- State Changes: None (persistence only).
- Exit Condition: After SaveAgentProperties and OnAutosave.

2.10 Stage: Death
-----------------
- Stage Name: Death (terminal for pulse loop).
- Trigger: Internal condition: GomeostasSystem.CheckForCriticalState() sets
  IsDead when a vital parameter is <= CriticalMinValue or >= CriticalMaxValue.
  ProcessAgentPulse checks AppGlobalState.IsDead after UpdateStateOnly.
- Active Modules/Classes: GomeostasSystem, GlobalTimer, AppGlobalState.
- Key Methods: GomeostasSystem.CheckForCriticalState() → _agentState.IsDead = true,
  AppGlobalState.IsDead = true, OnAgentDeath(param); in ProcessAgentPulse:
  SafeStopWithAgentDeath().
  SafeStopWithAgentDeath: _isRunning = false; OnPulsationStopped();
  OnPulseError?.Invoke("Агент умер"); StopTimers().
- Data Flow:
  - Input: _agentState.Parameters (vital, CriticalMinValue, CriticalMaxValue).
  - Output: Pulse loop stops; UI notified via OnPulseError.
- State Changes: IsDead true; timers stopped; pulse state cleared (OnPulsationStopped).
- Exit Condition: Loop does not run again until host restarts.

2.11 Stage: Evolution Stage (Developmental Stages 0–5)
-------------------------------------------------------
**Important Note on Semantics:** The method names "ClearConditionedReflexes", 
"ClearAllAutomatizm", etc. are misleading. They do NOT delete the data permanently.
Instead, they implement a "freezing" mechanism where lower-level structures become
read-only (locked for manual editing) when moving to higher stages. Data persists
and continues to influence behavior automatically, but direct manipulation is
blocked. True deletion only occurs when moving DOWNWARDS (regressing to an earlier
stage), as higher-level structures depend on the integrity of lower levels.

- Stage Name: Evolution stages 0–5 (developmental modes).
- Trigger: Explicit host/UI call to EvolutionStageService.ChangeEvolutionStage(
  targetStage, force, skipDataClearing). Not time-based; not part of the pulse.
- Active Modules/Classes: EvolutionStageService, AppGlobalState,
  ConditionedReflexesSystem, AutomatizmSystem, AutomatizmTreeSystem,
  EpisodicMemorySystem, ProblemTreeSystem.
- Key Methods: EvolutionStageService.ChangeEvolutionStage(targetStage, force, skipDataClearing);
  GetStageInfo(). 
  
  **Behavior:**
  - **Moving FORWARD (e.g., 0→1, 1→2, 2→3, 3→4, 4→5):** 
    - The system "freezes" the current stage's structures. For example, at stage 2,
      conditioned reflexes become locked for manual editing but remain active
      automatically. No data is erased.
    - The "ClearX" methods in this context indicate making structures read-only,
      not deleting them.
  
  - **Moving BACKWARD (e.g., 5→4, 4→3, 3→2, 2→1, 1→0):**
    - Higher-stage data that depends on the new lower stage must be deleted
      because the foundational structures have changed. For example:
      - Moving from stage 4 to 3: Episodic memory (thinking) is deleted because
        emotions (stage 3) cannot support it.
      - Moving from stage 3 to 1: Automatisms (stage 2) and emotions (stage 3) are
        deleted because conditioned reflexes (stage 1) are the new foundation.
      - Moving from stage 1 to 0: All conditioned reflexes are deleted because
        only unconditioned reflexes remain.
  
  This asymmetry is intentional: foundations can be rebuilt, but superstructures
  cannot survive foundation changes.

- Data Flow:
  - Input: targetStage 0–5, force (allow skip/back), skipDataClearing.
  - Transform: Validation (0–5; forward only one step unless force; backward
    requires confirmation or force). 
    - If targetStage < currentStage (moving down): ClearSubsequentStagesData(targetStage)
      permanently erases all data for stages above targetStage.
    - If targetStage > currentStage (moving up): No data clearing; only access
      restrictions change (freezing).
    - If forward jump with force: ClearIntermediateStagesData only for skipped
      stages? (Implementation detail).
    AppGlobalState.EvolutionStage = targetStage.
  - Output: EvolutionStageChangeResult (Success / RequiresConfirmation / Failure);
    persisted data deleted only when downgrading.
- State Changes: AppGlobalState.EvolutionStage; when downgrading: conditioned
  reflexes, automatisms, tree, episodic memory, problem tree are physically deleted.
  When upgrading: data persists but becomes read-only for manual editing.
- Exit Condition: Return EvolutionStageChangeResult.

Stage names (GetStageDescription): 
0 = Безусловные рефлексы (Unconditioned reflexes)
1 = Условные рефлексы (Conditioned reflexes)
2 = Автоматизмы (Automatisms)
3 = Эмоции (Emotions)
4 = Мышление (Thinking)
5 = Сознание (Consciousness)

2.12 Stage: Sleep (Planned / Stub)
----------------------------------
- Stage Name: Sleep
- Trigger: Intended when sleepingType > 0 passed to ProcessPsychicPulse. Currently
  sleepingType is always 0 in GlobalTimer (comment: “флаг сна получить когда класс сна будет”).
- Active Modules/Classes: PsychicSystem (ProcessSleep branch), GomeostasSystem
  (parameter speed reduced when IsSleeping).
- Key Methods: PsychicSystem.ProcessPsychicPulse(..., sleepingType): if sleepingType > 0
  set IsSleeping, IsSleepingDream; else awake. If IsSleeping: ProcessSleep() instead
  of normal awake logic. GomeostasSystem.UpdateStateOnly: if IsSleeping, delta100 /= 10.
- Data Flow: When implemented: sleep flag from “sleep class”; ProcessSleep() runs;
  reflex pulse skipped when IsSleeping.
- State Changes: IsSleeping, IsSleepingDream; parameter drift reduced.
- Exit Condition: Planned: when sleep class sets sleepingType back to 0. Currently
  N/A (stub).

3.1 Internal Data Structures (Across Stages)
--------------------------------------------
- AppGlobalState (static, thread-safe via ReaderWriterLockSlim): EvolutionStage,
  Lifetime, IsDead, IsSleeping, IsNewConditions, CurrentOverallState, DominantParam,
  ActiveStyles, ActiveAdaptiveActions, GeneticReflexesActions, ConditionedReflexesActions,
  CurrentGeneticReflexID, DetectedReflexNodeId, CurrentActiveAutomatizmId,

  WaitingForOperatorEvaluation, WaitingPeriodCountdown, ObservationMode, etc.
- GlobalTimer: GlobalPulsCount; _secondsSinceLastSave; _isRunning; references to
  Gomeostas, AdaptiveActionsSystem, ReflexesActivator, PsychicSystem,
  ConditionedReflexesSystem, ConditionedReflexFormationService.
- GomeostasSystem: _agentState (parameters, state, styles, Lifetime, IsDead,
  IsSleeping, etc.); _previousParametersState; _previousOverallState;
  _previousActiveStyleIds; HasCriticalChanges.
- ReflexesActivator: _activeCurBaseID, _activeCurStyleID, _activeCurTriggerStimulusID,
  _chainCooldownUntilPulse, _pendingChainId, _pendingChainActivationPulse,
  _geneticReflexesToRun, _conditionedReflexesToRun, _completedReflexesInChain,
  chain/reflex IDs.
- ConditionedReflexesSystem: _conditionedReflexes (dict); _currentAgentLifetime;
  settings from file.
- PsychicSystem: PulseCount, LifeTime, IsSleeping, IsSleepingDream, current/previous
  automatism IDs, waiting state, WakeUppingActivation.
- AdaptiveActionsSystem: _activeActions, _activeActionPhrases (reflex display
  duration).
- Queues/buffers: No explicit message queue; “pending” chain in ReflexesActivator;
  reflex/automatism “to run” lists per pulse.

3.2 Long-Term Storage (Files)
-----------------------------
- Paths: Under config folders (e.g. BaseDirectory subdirs). No database or vector
  store in engine; all persistence is file-based.
- Gomeostas (GomeostasSystem): StylesFileName.dat, AgentParametersFileName.dat,
  AgentPropertiesFileName.dat (GomeostasFolderPath). SaveAgentProperties() writes
  name, description, IsSleeping, IsDead, Lifetime, EvolutionStage, PainValue,
  JoyValue, archetype, motivation, temperament, etc.
- Conditioned reflexes: ConditionedReflexesFileName.dat, ConditionedReflexSettingsFileName.dat
  (Reflexes folder). SaveConditionedReflexes(), LoadConditionedReflexSettings().
- Reflexes: GeneticReflexesFileName.dat (GeneticReflexesSystem); ReflexTreeFileName.dat
  (ReflexTreeSystem); ReflexChainsFileName.dat (ReflexChainsSystem).
- Psychic: Under PsychicDataFolder (e.g. Data\Psychic): AutomatizmTreeFileName.dat,
  AutomatizmFileName.dat, AutomatizmChainsFileName.dat; ProblemTreeFileName.dat;
  EpisodicTreeFileName.dat, EpisodicHistoryFileName.dat; ActionsImagesFileName.dat,
  InfluenceActionsImagesFileName.dat, VerbalBrocaImageFileName.dat,
  EmotionsImageFileName.dat.
- Actions: ActionsFileName.dat (AdaptiveActionsSystem), InfluenceActionsFileName.dat
  (InfluenceActionSystem).
- Perception: PerceptionImagesFileName.dat (PerceptionImagesSystem).
- Sensors: Verbal channel WordTree, PhraseTree, WordSandbox, PhraseSandbox (Load/Save).
- Logs: ResearchLogger — AgentLogs.jsonl, AgentLogs_Parameters.jsonl,
  AgentLogs_Styles.jsonl (LogsFolder).

3.3 Persisted Between Restarts
------------------------------
- Agent: Agent properties (including IsSleeping, IsDead, Lifetime, EvolutionStage),
  parameters, styles (all via GomeostasSystem load/save).
- Reflexes: Genetic reflexes, reflex tree, reflex chains, conditioned reflexes and
  their settings.
- Psychic: Automatizm tree, automatisms, automatism chains; problem tree; episodic
  memory tree and history; action images, influence action images, verbal Broca
  images, emotions images.
- Actions: Adaptive actions, influence actions.
- Perception images.
- Sensor verbal trees/sandboxes.
- Boot data: GeneticReflexFileLoader, AutomatizmFileLoader load from BootDataFolder
  (e.g. GeneticReflexLoadResult LoadFromFile(), AutomatizmFileLoader.LoadFromFile(...)).
  Conditioned reflex settings file is loaded on init. No explicit “save on exit”
  for all subsystems; autosave every 10 s and SaveAgentProperties on
  IsidaContext.Dispose() and StopTimers() ensure agent state is persisted.

4.3 Events (GlobalTimer)
-------------------------

4.6 Configuration Parameters That Affect Behavior
-------------------------------------------------
From IsidaConfig: DefaultStileId, CompareLevel, DifSensorPar, DynamicTime,

behavior (e.g. ProcessPsychicPulse returns if EvolutionStage < 2; GlobalTimer.Start
requires EvolutionStage >= 1).
